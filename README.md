# Lify v1.0

Lify est une application simple de gestion de tâches quotidiennes. Elle vous permet d'ajouter, de compléter et de supprimer des tâches pour organiser votre vie au quotidien.

## Fonctionnalités

- Ajouter une nouvelle tâche
- Marquer une tâche comme terminée
- Supprimer une tâche
- Interface intuitive et responsive

## Installation

Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré.

## Utilisation

1. Saisissez le nom de votre tâche dans le champ de texte
2. Cliquez sur "Ajouter" ou appuyez sur Entrée
3. Cliquez sur une tâche pour la marquer comme terminée
4. Cliquez sur la croix pour supprimer une tâche
